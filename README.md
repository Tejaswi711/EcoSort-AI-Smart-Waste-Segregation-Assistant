# EcoSort AI – Smart Waste Segregation Assistant

##  Project Overview

EcoSort AI is a simple AI-powered waste segregation assistant that helps users understand how to properly classify and dispose of different waste items.

The user enters the name of a waste item, and the AI provides its waste category, recommended bin, disposal method, sustainability tip, and safety note.

## SDG Alignment

**SDG 12 – Responsible Consumption and Production**

The project supports responsible waste management by helping people understand proper waste segregation and disposal.

## Problem Statement

Waste segregation is a common problem in homes, schools, and communities. People may not know which bin to use for different waste items such as plastic bottles, food waste, batteries, and electronic items.

Improper waste segregation can make recycling difficult and increase environmental pollution.

EcoSort AI provides simple AI-based guidance to make waste segregation easier and encourage responsible waste management.

## Solution

EcoSort AI uses AI to analyze the waste item entered by the user and provides:

- Waste Category
- Recommended Bin
- Disposal Method
- Sustainability Tip
- Safety Note

## How It Works

1. User enters a waste item.
2. The input is sent to the AI model.
3. The AI analyzes the waste item using a predefined prompt.
4. The AI returns a structured response.
5. EcoSort AI displays the result in an easy-to-understand format.

## Example

**Input:** Plastic bottle

**Output:**
- Waste Category: Recyclable Waste
- Recommended Bin: Recycling Bin
- Disposal Method: Clean and recycle where accepted
- Sustainability Tip: Prefer reusable bottles
- Safety Note: Follow local recycling guidelines

## Responsible AI

The project follows responsible AI practices by:

- Avoiding unnecessary personal information
- Providing simple and transparent guidance
- Avoiding dangerous disposal recommendations
- Advising users to follow local waste-management rules
- Providing safety information for hazardous waste

## Expected Impact

EcoSort AI aims to:

- Make waste segregation easier
- Encourage recycling
- Reduce improper waste disposal
- Increase awareness about responsible waste management

## Limitations

- Waste-management rules can vary by location.
- Text-based input may sometimes be unclear.
- The AI guidance is educational and should not replace official local disposal instructions.
